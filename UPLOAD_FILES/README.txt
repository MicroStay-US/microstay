HOW TO USE:
===========

STEP 1: Open GitHub
Go to: https://github.com/MicroStay/MicroStay_Bolt

STEP 2: Update Each File
For each .tsx file:
  a) Navigate to the file on GitHub
  b) Click the pencil icon (Edit)
  c) Select all and delete
  d) Copy content from the corresponding file here
  e) Paste it
  f) Commit changes

For BILLING_SYSTEM.md:
  a) Click "Add file" → "Create new file"
  b) Name it: BILLING_SYSTEM.md
  c) Copy content from BILLING_SYSTEM.md here
  d) Paste it
  e) Commit new file

STEP 3: Wait for Deploy
- Vercel will automatically deploy (2-3 minutes)
- Check deployment at: https://vercel.com/info-43850757s-projects/micro-stay-bolt/deployments

STEP 4: Test
- Login as admin → check for "Monthly Invoices" tab
- Login as vendor → check for "Billing" tab
